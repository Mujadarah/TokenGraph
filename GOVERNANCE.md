# TokenGraph governance

TokenGraph is maintained by Mujadarah. The maintainer is responsible for the roadmap, repository settings, review decisions, merges, security responses, releases, and project naming.

Community members participate through issues, discussions, forks, and pull requests. A contribution may be accepted, revised, deferred, or declined based on project scope, maintainability, security, compatibility, evidence, and review quality.

Direct write access is not required for participation and is granted only by the maintainer when needed. Protected branches, protected release tags, required pull requests, required checks, and review requirements apply independently of the Apache License 2.0. The license permits use and modification of the code; it does not grant administrative control of this GitHub repository.
