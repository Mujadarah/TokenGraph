# Security policy

## Supported versions

Security fixes target the latest published TokenGraph release and the current `main` branch.

## Report a vulnerability privately

Do not open a public issue for a suspected vulnerability. Use the repository's [private vulnerability reporting](https://github.com/Mujadarah/TokenGraph/security/advisories/new) so the maintainer can investigate before details are disclosed.

Include:

- the affected TokenGraph version and installation method;
- the host, operating system, and relevant configuration;
- a minimal reproduction or proof of concept;
- the expected and observed security boundary;
- the potential impact and any known workaround.

Do not include real secrets, private source code, or personal data. Reports are assessed on a best-effort basis, and public disclosure should be coordinated after a fix or mitigation is available.
